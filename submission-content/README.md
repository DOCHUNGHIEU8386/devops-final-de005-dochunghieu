# Thư mục nộp bài (submission-content)

Thư mục này chứa toàn bộ các tệp minh chứng khi nộp bài theo yêu cầu của hội đồng thi:

1. File thông tin sinh viên và cấu hình: `student.env`
2. Các tệp cấu hình cốt lõi: `Dockerfile`, `docker-compose.yml`, `ci-cd.yml`
3. Ảnh chụp minh chứng (copy từ thư mục `screenshots/`):
   - `01-actions.png`
   - `02-ghcr.png`
   - `03-compose-ps.png`
   - `04-website.png`
4. Báo cáo kết quả hoặc link repository / IP triển khai.
